## 五、如何查看这些作品

1. **只看网页**：直接双击对应的 `.html` 文件，浏览器即可打开（部分页面需要联网调用接口）。
2. **克隆到本地**：

   ```bash
   git clone <本仓库地址>
   cd ncu-ai-portfolio-5807126068
   ```

3. 目录里的 `.docx` / `.pptx` 用 Office 或 WPS 打开即可。

> 提示：涉及第三方接口的页面，请自行在代码中填入自己的 API Key；仓库内不会保存任何密钥。
