# STORY.md — 大学生必备AI工具使用指南

## ① 用户意图对齐

- **目标受众**：高校在校生（本科为主，兼顾低年级研究生）。使用场合为新生分享会 / 学习经验交流 / 社团技能培训，现场投影讲述为主、会后可自行翻阅。
- **核心目标**：让同学在 5 分钟内看懂"三类 AI 工具分别解决什么校园痛点"，并记住一条底线——**AI 是副驾驶，不是代笔**；听完能当场试用其中一类工具。
- **PPT 长度**：5 页。短篇，不设目录与章节扉页（0 个章节 → 0 个 `section` 扉页，契约成立）。Hero 页配额取下限 1 页（20%）。
- **视觉调性**：理性、清晰、可信、结构化、克制。
- **内容边界**：
  - 必讲——三类工具的能力边界 + 真实校园使用场景 + 使用原则；
  - 不讲——具体订阅价格、账号注册教程、厂商优劣排名；
  - 禁碰——任何鼓励代写论文、代做作业、考试作弊的用法。

## ② 页面布局骨架

5 页一镜到底：**封面 → 三类工具各一页 → 总结**。不设目录页与章节扉页（短篇不为了形式牺牲内容）。
Hero 页仅 **P1 封面**（1/5 = 20%，落在 20–30% 区间）。P5 结尾页以收束金句 + 使用原则收尾，视觉强度接近封面但按 supporting 处理，以保证 Hero 占比合规且全局只有 1 处"视觉爆发"。

| 页 | 角色 | rhythm | 说明 |
| :- | :--- | :--- | :--- |
| P1 封面 | **hero** | peak | 全幅主视觉 + 骑线标题 |
| P2 工具一 | supporting | valley | 信息承载，高密度 |
| P3 工具二 | supporting | **peak** | 打破 valley 连排，视觉重量提升 |
| P4 工具三 | supporting | valley | 高密度承接 |
| P5 总结 | supporting | **peak** | 收束金句 + 巨型数字锚点 |

- **rhythm 曲线**：peak → valley → peak → valley → peak，无连续 ≥3 页 valley。
- **版式预算**：非对称版式 4/5 页（80% ≥ 40%）✓；对称版式仅 P5 一页（≤2）✓；`N卡片横排` 全篇 0 次 ✓；`左大图+右侧文字` 与 `非对称双栏` 合计 2 页（40% ≤ 40%）✓；相邻两页版式均不同 ✓。

## ③ 页面大纲

### P1 · 封面
- `title`：大学生必备AI工具使用指南
- `type`：cover ｜ `role`：hero ｜ `rhythm`：peak
- `layout`：全幅图+骑线文字
- `visual`：`L1: cover_campus_ai.png（满幅铺底，左 45% 被文字骑行覆盖）+ L3: 靛蓝方形角标`
- `visual_role`：atmosphere
- `density`：字数约 40 / 图片 1 张 / 留白约 40%
- `anti_pattern`：禁止标题栏右侧塞 200×70 装饰小图；禁止纯色矩形 + 单行文字的平铺式封面；禁止正文段落铺满封面
- `description`：副标题「**——零基础入门，快速上手**」点明门槛与价值；辅以标签「三类工具 · 读 · 写 · 做」给出观看理由——看完就能挑一个用起来。

### P2 · 工具一：长文档阅读助手
- `title`：工具一 · 长文档阅读助手
- `type`：content ｜ `role`：supporting ｜ `rhythm`：valley
- `layout`：左大图+右侧文字
- `visual`：`L1: tool1_reading.png（占左 55%）+ L3 角标`
- `visual_role`：anchor
- `density`：字数约 210 / 图片 1 张 / 留白约 25%
- `anti_pattern`：禁止 50:50 等分双栏；禁止把工具截图缩成小贴片；禁止只罗列功能名词而不给场景
- `description`：**工具名称**：长文档阅读助手（Kimi / 豆包 / NotebookLM）。
  - **一句话定位**：把上百页文献「读薄」，先看懂、再精读。
  - **3 个核心功能**：① 长文速读——上百页 PDF / 课件一次投喂，自动出摘要与提纲；② 追问释义——圈出读不懂的段落逐句追问，像助教一样讲透；③ 跨文对比——多篇文献一键比对观点与结论，快速定位差异。
  - **适用场景**：期末带 5 篇英文文献先出摘要再精读 · 200 页课件压缩成一页提纲 · 预习时判断文章值不值得细读。
  - **上手难度**：★☆☆（极易上手 · 会打字就会用）
  - 判断句：文献越厚，AI 的"先读后筛"价值越大，但它替你筛不掉理解。

### P3 · 工具二：通用写作与答疑助手
- `title`：工具二 · 通用写作与答疑助手
- `type`：content ｜ `role`：supporting ｜ `rhythm`：peak
- `layout`：顶部定位条 + 下部左功能卡 / 右竖图
- `visual`：`L1: tool2_writing.png（占右 40%，底部叠「适用场景」浮层）`
- `visual_role`：evidence
- `density`：字数约 230 / 图片 1 张 / 留白约 20%
- `anti_pattern`：禁止左右 50:50 等分；禁止把「一句话定位」写成宣传口号；禁止把它写成"万能神器"式宣传
- `description`：**工具名称**：通用写作与答疑助手（DeepSeek / ChatGPT / 文心一言）。
  - **一句话定位**：随身「第二大脑」——写作与答疑的效率搭子。
  - **3 个核心功能**：① 对话答疑——多轮追问把模糊问题逼到具体，还能指定角色扮演面试官、审稿人；② 写作润色——论文、报告与英文作文的起草、扩写与语言润色，先给一版能改的初稿；③ 代码调试——定位报错原因、解释代码逻辑，给出可运行的修改方案。
  - **适用场景**：代码报错找不到原因 · 英语作文找人批改 · 答辩前模拟被提问。
  - **上手难度**：★★☆（需一点提示词技巧）
  - 判断句：写作效率可提升约 3 倍，但前提是**框架得你自己先给**——AI 擅长扩写，不擅长替你立意。

### P4 · 工具三：演示与创意生成
- `title`：工具三 · 演示与创意生成
- `type`：content ｜ `role`：supporting ｜ `rhythm`：valley
- `layout`：左靛蓝色块栏（工具名 + 定位 + 场景）+ 右内容（横图 + 功能列表）
- `visual`：`L1: tool3_creating.png（右侧上沿横图）+ 左侧靛蓝色块栏`
- `visual_role`：evidence
- `density`：字数约 205 / 图片 1 张 / 留白约 22%
- `anti_pattern`：禁止等宽四卡横排；禁止把三个能力硬塞进同一种卡片造型；禁止内容超出右侧 66% 栏宽
- `description`：**工具名称**：演示与创意生成（Gamma / 可画 / 剪映 / 即梦）。
  - **一句话定位**：把一句话想法，直接变成能展示的成品。
  - **3 个核心功能**：① 一键成稿——说清主题、页数与风格，几分钟拿到可开讲的 PPT 初稿；② 海报与图表——招新海报、活动宣传图与数据可视化，描述清楚即可出图；③ 短视频与配图——脚本、分镜、配图与字幕一起生成，剪辑节奏先出方案。
  - **适用场景**：小组作业与课程汇报 · 社团招新与活动海报 · 课程展示短视频。
  - **上手难度**：★★★（需练习提示词与审美）
  - 判断句：从想法到可讲初稿平均省下约 2 小时，省下的是排版时间，**不是思考时间**——模板救不了没观点的人。

### P5 · 总结：把 AI 用成副驾驶
- `title`：把 AI 用成副驾驶
- `type`：ending ｜ `role`：supporting ｜ `rhythm`：peak
- `layout`：居中金句/巨型数字
- `visual`：`大数字「3」+ 三条要点 + 收束金句`
- `visual_role`：anchor
- `density`：字数约 150 / 图片 0 张 / 留白约 35%
- `anti_pattern`：禁止把三条要点装进三张等宽卡片；禁止逐条复述三类工具的完整名称与功能；禁止只喊口号不给可执行动作
- `description`：一句话收束——**先自己想，再让 AI 拓展，最后人工核验**。三条要点：
  - ① **读 · 先读后筛，再回原文核对**：长文档助手帮你快速判断重点，但真正的理解必须回原文自己完成。
  - ② **写 · 先搭框架，再让 AI 扩写**：写作与代码交给助手提速，但立意、结构与结论由你拍板。
  - ③ **做 · 先有观点，再交给模板**：演示、海报、视频能一键生成，省下的是排版时间，不是思考时间。
  - **下一步行动**：① 选一个工具上手 → ② 用它完成一件真实作业 → ③ 复盘 AI 帮到你的地方与必须自己判断的地方。
  - 收束金句：**工具决定效率，判断力决定成绩**。
