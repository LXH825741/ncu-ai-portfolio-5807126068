# DESIGN.md — 大学生必备AI工具使用指南

> 风格路线：**通用设计原则（universal-only）**。主题属"技术科普 / 学习分享"，不落在学术科研、专业咨询、党政红色三个垂直分支内，故不引用任何 `design-principle.<id>.md` 分支，全部常量值由本文件定义。
> 视觉气质取自用户选定的 **D · 靛蓝学术** 预览卡：浅蓝白底 + 深靛蓝主色 + 亮蓝点缀，结构化、理性、可信。

## 1. 画布与母版（A / B / C 三区）

- **画布**：1280 × 720 px（16:9）
- **Slide padding**：`24px 64px`（上下 24px、左右 64px）——安全区，不得用绝对定位绕过
- 可用内容区：**1152 × 672 px**

| 母版区 | 页面绝对 y | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 24–120px | 96px | 主标题 34px bold `#1E3A8A`；左侧 6px 宽 `#2563EB` 竖条作标题锚；右上角可选小标签 14px |
| **B · 内容区** | 120–636px | 516px | 一切正文、卡片、配图、图表；禁止挤占 A / C 区 |
| **C · 页脚条** | 636–696px | 60px | 左：`大学生必备AI工具使用指南`（14px `#9CA8C4`）；右：页码 `NN / 05`（14px `#9CA8C4`） |

- **封面（01）**：自定义版式——左侧 520×720 深靛蓝色块标题栏 + 右侧 760×720 满高主视觉，保留页码 `01 / 05`（置于左栏底部右下角）。
- **结尾（05）**：自定义版式，居中金句 + 巨型数字，保留右下页码 `05 / 05`。
- 内容页（02–04）之间 A / B / C 三区位置与尺寸**逐页完全一致**。

## 2. 颜色系统（≤ 4 hex）

| 角色 | Hex | 用途 |
| :--- | :--- | :--- |
| **背景** | `#F4F7FF` | 全篇页面底色（浅蓝白） |
| **主色** | `#1E3A8A` | 标题文字、左侧色块栏、封面蒙版、深色元素 |
| **辅色 / 强调色** | `#2563EB` | 标题竖条、卡片描边、巨型数字、图标、强调词 |
| **文本** | `#111827` | 正文、说明文字 |

**派生色（仅由上述 4 色加透明度生成，不引入新 hex）**
- `rgba(37,99,235,0.10)` — 卡片浅蓝底 / 图标底
- `rgba(37,99,235,0.22)` — 分隔线、卡片描边
- `rgba(30,58,138,0.55)` — 封面图片蒙版（保证白字可读）
- `rgba(30,58,138,0.08)` — 大色块衬底
- `#9CA8C4` 以 `rgba(30,58,138,0.45)` 表达（页脚灰蓝字）

### 2.1 色彩面积分配

| 色彩角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 背景 `#F4F7FF` | ≈ 55–70% | 页面底色 |
| 主色 `#1E3A8A` | ≤ 40% | 左色块栏、封面蒙版、标题 |
| 辅色 `#2563EB` | ≤ 20% | 卡片、描边、图标 |
| 强调 `#2563EB` 高饱和 | ≤ 10%（Hero 页可至 15%） | **只出现在焦点元素**：巨型数字、标题竖条、关键判断句 |

**页面色彩节奏**：01 封面为深色主导（左栏主色色块 ≈ 41% + 右侧主视觉），02 / 04 为浅底 + 中等主色（≈ 30–40%），03 为浅底 + 强调色 8%，05 为浅底 + 强调色 12%。全篇至少 3 页色彩比例显著不同，不雷同。

### 2.2 渐变与半透明策略

- **允许**：封面底图叠加 `rgba(30,58,138,0.55)` 蒙版；
- **允许**：卡片使用 `boxShadow: '0 4px 20px rgba(30,58,138,0.08)'`；
- **允许**：`linear-gradient(135deg, #1E3A8A 0%, #2563EB 100%)` 用于封面左下 6px 竖条与 05 页巨型数字底衬**（全篇最多 2 处，其余一律纯色）**；
- **禁止**：高饱和撞色铺满 ≥ 1/3 页面；同页出现两套主色板。

## 3. 字体系统

**字体家族（共 2 套）**
- 中文：`微软雅黑`（标题 Bold，正文 Regular）
- 西文 / 数字：`Arial`（Bold）

| 层级 | 字号 | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 66px | bold | 1.15 | 仅 01 页 |
| 巨型数据 / 锚点数字 | 96px | bold | 1.0 | 05 页「3」 |
| 结尾金句 | 52px | bold | 1.2 | 仅 05 页 |
| 页面主标题（A 区） | 34px | bold | 1.3 | 02–05 固定 |
| 卡片小标题 / 副标题 | 24px | bold | 1.4 | 卡片头、栏目标题 |
| 正文 | 22px | regular | 1.6 | 段落与要点 |

- 锚点数字（96px）与正文（22px）字号差 4.4 倍，字重 bold vs regular，满足"锚点必须与正文不同字重"的要求。

## 4. 信息密度门禁

| 页面 | 最少元素 | 正文字数 | 图 / 表 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- | :--- |
| 01 封面 | 主标题 + 副标 + 主视觉 | ≥ 40 | 1 | ≥ 35%（满幅） |
| 02 内容页 | 标题 + 正文 + 主视觉 | ≥ 180 | 1 | ≥ 40% |
| 03 内容页 | 标题 + 定位条 + 正文 + 图 | ≥ 180 | 1 | ≥ 30% |
| 04 内容页 | 标题 + 3 要点 + 主视觉 | ≥ 180 | 1 | ≥ 30% |
| 05 结尾 | 金句 + 3 原则 + 锚点数字 | ≥ 120 | 0 | ≥ 40%（数字 + 色块） |

- **留白上限**：常规内容页 ≤ 35%。01 / 05 为 hero / 收束页，允许 35–40%。
- **容器填充率**：卡片内容垂直占用 ≥ 卡片高度 85%；卡片尾部元素（引文条 / 标签条）用 `marginTop: 'auto'` 钉底。
- **横向兄弟卡对齐**：同排卡片的标题块 / 正文块 / 尾部元素 y 坐标差 ≤ 16px。

## 7. 逐页自检清单（生成每页时逐项确认）

1. 母版三区齐全（A 24–120 / B 120–636 / C 636–696，页码 NN / 05）
2. 标题块右侧无 200×70 装饰小图，全篇标题位置一致
3. L1 主视觉占 B 区 ≥ 30%（02 页 ≥ 40%）
4. 全页仅使用本文件列出的 4 个 hex 及其透明度派生色
5. 与上一页版式不重复；留白 ≤ 本页规定上限
6. 本页 ≥ 1 个视觉锚点（≥ 44px 元素 或 ≥ 40% B 区面积的图）
7. 与上一页视觉重量不同（版式结构明显不同或最大元素面积比 > 1.5:1）
8. 强调色只落在焦点元素上，面积符合第 2.1 节
9. `role` 与 STORY.md 一致；supporting 页不使用 hero 级视觉投入
